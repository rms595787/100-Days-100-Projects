## 🧠 What I Learned

- Blurring → gradually revealing images
- Using conversion formulas like:

  ```
  scale(num, in_min, in_max, out_min, out_max) =
  ((num - in_min) * (out_max - out_min)) / (in_max - in_min) + out_min
  ```

- Mapping values between ranges for smooth effects
