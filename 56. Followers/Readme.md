## 🧠 What I Learned

HTML allows developers to store custom data directly in elements using **data attributes**.

Example:

```id="wxtny3"
data-id="10"
```

JavaScript can access this using:

```id="8w0tqs"
element.dataset.id
```

This makes it easy to pass information between HTML and JavaScript.

I also explored:

- `Math.ceil()`
- `setTimeout()`
- `setInterval()`

These functions are commonly used to create **timed interactions and delayed animations**.
