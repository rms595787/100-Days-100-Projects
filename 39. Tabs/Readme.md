## 🧠 What I Learned

- How **position: static** opens up new layout possibilities
- Combining visibility + static positioning for amazing UI effects
- Learned pattern:

  ```js
  if (e.target.matches(".tab-item a")) {
    getTab(e.target);
  }
  ```

- How small JS checks can power big UI interactions.
