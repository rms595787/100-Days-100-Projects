## 🧠 What I Learned

- Flexbox advanced usage beyond centering
- Flex properties like:
  - `flex-grow`
  - `flex-shrink`
  - `flex-basis`

- Selector learned: `nth-of-type()`
- Also similar selectors such as:
  - `nth-child()`
  - `last-of-type`
  - `first-of-type`
